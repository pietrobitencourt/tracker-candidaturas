ETAPA 1 - LEVANTAMENTO DE REQUISITOS (MoSCoW)

MUST (V1)
- O sistema deve mostrar uma lista dos próximos eventos ordenados por data (etapas e provas), destacando os prazos próximos e os atrasados;
- O sistema deve registrar e listar as plataformas (nome, site, se tenho conta);
- O sistema deve permitir o cadastro de uma candidatura e listar as vagas em que me inscrevi;
- O sistema deve guardar os dados da vaga e da candidatura: empresa, cargo, plataforma onde a vaga foi encontrada, link, modalidade (remoto, presencial, híbrido), jornada (integral, meio-período), bolsa, currículo enviado, data de inscrição e contatos do recrutador (guardar só o necessário: nome e um meio de contato);
- O sistema deve guardar o histórico de etapas (inscrição, prova, entrevista, teste etc.), registrar a situação de cada etapa, permitir atualizá-la e sinalizar qual é a etapa atual;
- O sistema deve registrar e mostrar o desfecho do processo: em andamento, aprovado, reprovado, desisti, sem resposta, classificado, lista de espera, banco de talentos;
- O sistema deve permitir editar, excluir, buscar e filtrar por empresa, plataforma ou etapa;
- O sistema deve permitir registrar anotações em cada candidatura;
- O sistema deve rodar no meu computador;
- O sistema deve ter grid e layout responsivo, para web, tablet e celular.

SHOULD/COULD (V2)
- O sistema pode notificar quando abrir uma vaga, como no LinkedIn;
- O sistema pode dizer se meu currículo bate 100%, parcialmente ou pouco com os requisitos da vaga;
- O sistema pode avisar os prazos pelo Telegram ou Gmail;
- O sistema pode ter login para proteger o acesso aos dados;
- O sistema pode anotar o usuário ou e-mail de cada conta (nunca a senha).

WON'T POR ENQUANTO (V2.1)
- O sistema pode recomendar ou indicar locais para buscar estágio;
- O sistema deve respeitar a LGPD caso passe a guardar dados de terceiros além do necessário.
